# 帧提示词约定(每状态一个文件)

每个动画状态写一个 `.txt` 提示词,经 STDIN 传给 `generate-frames.sh`。结构 = 公共头 + 脚底基线约束 + 本状态逐帧描述 + 后处理流程。

## 公共头(角色锚定 + 绿幕)

> 附带参考图是这个角色的【唯一标准形象】(写明:配色、描边、风格,如「橘色虎斑,厚黑描边,大眼,扁平卡通 2D 游戏风」)。所有帧必须严格保持同一角色:同脸、同配色、同描边、同体型。背景必须整幅纯绿 `#00FF00` 平涂(用于抠像),无渐变/阴影/地面/文字/边框。

## 脚底基线约束(防漂移的根本,务必写入)

> 【关键-脚底基线】每一帧里角色脚底都必须落在画布同一条水平线上(约画布高度的 **78%** 处),角色水平居中。画布统一为正方形(如 1024×1024),四周留白一致。这样不同帧切换时不会上下/左右跳。

## 逐帧描述(示例:idle —— 幅度要小)

> 【动作幅度极小】身体、头、四肢、姿态在所有帧中完全不变,只有尾巴轻摆 + 偶尔眨眼。不要身体起伏、不要俯卧、不要站起、不要跳。
> - frame 1: 尾巴摆向左,睁眼
> - frame 2: 尾巴回中,睁眼
> - frame 3: 尾巴摆向右,睁眼
> - frame 4: 尾巴回中,闭眼眨眼(身体头部与前三帧完全一致)

挤压拉伸类(happy)要强调【原地】:脚不离基线,挤压拉伸只发生在身体(从脚底往上压扁/拉高)。

## 后处理流程(写入提示词尾部)

> 流程:先生成第 1 帧;其余帧以参考图 + 第 1 帧为参照严格保持同一角色,只改本帧描述的动作。每帧把纯绿背景去成真透明:`magick IN.png -fuzz 18% -transparent "#00FF00" OUT.png`【务必不要加 `-trim`,保留完整画布,使所有帧尺寸完全一致、脚底基线不变】。最终透明 PNG 保存到 `tmp/frames/<state>/frame_1.png ...`(逐帧),不要拼 sheet。结束时 `magick identify` 打印每帧绝对路径 + 尺寸(应全部相同)。

## 调用

```bash
# 可并行多状态:各自后台、各写不同 out-dir
bash .claude/skills/codex-image-assets/scripts/generate-frames.sh \
  --ref /tmp/ref/char_ref.png --prompt /tmp/prompts/idle.txt \
  --out-dir tmp/frames/idle --cwd "$PWD"
```

> 提示词风格:大写 `CRITICAL/关键` 标记比平铺更有效;给精确 hex;逐帧写位置;每次都重复绿幕 + 脚底基线要求。生成后必须逐帧人工 QA(角色一致性、绿边、基线)。
