# TTS：Agent 输出自动转语音

> 状态：已完成（2026-06-11）。
> 决策：系统语音走 renderer `speechSynthesis`（本地零配置）；自定义走 OpenAI 兼容 `/v1/audio/speech`（主进程发请求,音频 Buffer 回传播放）；触发点在 `handleCliExit`（与时间线插桩同位置）；新朗读打断旧朗读；文本截断 600 字。

## 设计

```ts
type TtsEngineConfig =
  | { kind: "system"; voice?: string; rate?: number }
  | { kind: "openai"; baseUrl: string; apiKey?: string; model: string; voice: string; speed?: number };
interface TtsSettings { autoSpeak: boolean; engine: TtsEngineConfig; }
```

- 持久化：PersistedState.ttsSettings；store + persistence 订阅。
- IPC：`tts:synthesize`（主进程 POST `{base}/v1/audio/speech`，返回音频 ArrayBuffer）。
- core `personal/tts.ts`：`speakText`（引擎分发 + 打断）/ `stopSpeaking` / `clipSpeechText`（截断 + 去 markdown 噪声）。
- 设置「语音」tab：自动朗读开关、引擎选择、系统音色（中文优先）/语速、自定义端点字段、试听/停止按钮。
