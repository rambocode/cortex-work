设计方向

没有品牌约束时，从以下五个方向中选择一个并贯彻到底。不要混合拼凑。

Editorial
出版编辑

印刷杂志 · 克制 · 严肃

衬线标题 + 安静无衬线正文。纸墨中性色，一个收敛强调色。强留白，用边框代替阴影。

避免：SaaS 仪表盘、商业控件、圆角卡片网格。

Modern Minimal
现代极简

精确 · 安静 · 软件原生

高品质无衬线系统，紧排版追踪，表格数字。中性表面、清晰边框、一个可见的产品强调色。

避免：单色空洞、装饰渐变背景、大号营销 Hero。

Human
亲切亲和

友好 · 温暖 · 清晰

圆润人文显示字体，可读正文。干净的中间色基座，产品驱动的色彩；温馨但不甜腻。

避免：过度卡通插图、Emoji 图标、假亲切感。

Tech Utility
技术工具

密集 · 务实 · 面向操作者

一个强有力的无衬线家族，等宽字体用于代码 / 指标 / ID。中性深色或浅色，信号色标识状态。

避免：Hero 大图、超大标题、装饰性卡片、营销文案。

Brutalist
粗野实验

原始 · 自信 · 排版驱动

超大衬线显示 + 等宽正文。纸张中性色、强劲边框、一个炽热强调色。非对称布局。

避免：阴影、渐变、圆角抛光 SaaS 镀铬。

工艺准则

最终交付前的质量门。每条规则都经过真实产品验证。

排版
全文档最多 6-8 种字号。展示字体搭配宁静正文字体。正文 15-18px，行高 1.5-1.6。行宽约 50-75 字符。全大写标签间距 0.06-0.1em。
展示层级 · Display
正文示例：保持行长在 50–75 字符之间，用 max-width: 65ch 是可靠的默认选择。使用三种字重：阅读、强调、宣告。
const tabular = metrics.length

色彩
按角色命名 token：背景、表面、前景、次级、边框、强调色。强调色每屏最多 1-2 处。正文对比度约 4.5:1。避免纯黑纯白大面积使用。

布局
使用稳定尺寸避免状态变化导致的布局抖动。不要在卡片内嵌套卡片。工具界面优先密度与可预测导航。不要套模板式地让每个段落等宽等距等圆角。
动效
动效服务于状态反馈，不服务于装饰。使用 opacity + transform 保证性能。入场约 200ms，出场约 140ms。尊重 prefers-reduced-motion。 
transition: opacity .2s, transform .2s;
transition-timing-function: cubic-bezier(0.23, 1, 0.32, 1);

UI 组件指南

每个元素都应为用户工作流服务，用熟悉的控件替代装饰性替代品。

按钮与操作

清晰层级：主要 / 次要 / 幽灵 / 危险。图标按钮保持正方形稳定尺寸，配无障碍标签。使用具体动词代替「提交」。

导航

按信息架构选导航类型：小应用用顶栏，工作区用侧边栏，同级用标签页，深层嵌套用面包屑。

侧边栏适合管理后台 标签页用于同级视图
卡片与面板

卡片用于重复对象、可选择项、摘要。不嵌套卡片。一个卡片应有一个主主体、一个关键指标、一个明确操作。

禁止嵌套卡片
表单与输入

标签保持可见，占位符不是标签。字段附近校验，组级错误汇总。
Select 用于小型固定集合，Combobox 用于大集合。

表格

表格用于比较。使用表格数字对齐指标、金额、日期。提供筛选项、排序、状态 Chip、空态与加载骨架。

图表与指标

按问题选图：趋势用折线，对比用柱状，组成用堆叠柱，相关性用散点。标注坐标轴、单位、图例。

折线 → 趋势 柱状 → 对比

语义 HTML

使用真正的按钮、链接、标题层级。

避坑指南

发货前排查这些常见的 AI 设计通病。

勿用
  • 无理由的紫蓝渐变 Hero
  • Emoji 作为功能图标
  • 彩色左边框圆角卡片
  • 三段等宽卡片作为页面全部内容
  • 「10x 加速」「99.9% 可用率」等假指标
  • Lorem ipsum 或「功能一」「功能二」
  • 装饰性 blob / 波浪背景
  • 每段等距等圆角等居中的模板感
应用
  • 语义化 HTML 与可访问控件
  • 按角色命名的 CSS 变量
  • CSS Grid / Container Queries 作为主布局
  • 真实或诚实的内容，不编造数据
  • 一个果断的华彩而非多个竞争效果
  • 包含加载、空态、错误、成功的完整状态
  • 使用比例克制、语义明确的强调色
  • 交付前自我评分：理念 / 层次 / 执行 / 特异性 / 克制
