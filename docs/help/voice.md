# 使用语音功能

在 Cortex Desktop 中打开「设置 → 语音」，可以统一配置麦克风、语音聊天、听写和语音识别模型。

## 选择麦克风

1. 进入「设置 → 语音 → 常规」。
2. 第一次打开时，允许 Cortex 使用麦克风。
3. 在「麦克风」下拉框中选择设备；选择「系统默认」会跟随 macOS 的默认输入设备。

如果设备名称显示为「麦克风 1」之类的编号，通常是尚未允许麦克风权限。允许后重新打开设置即可看到系统提供的设备名称。

## 朗读语音（TTS）

在「设置 → 语音 → 语音聊天」卡片的「语音引擎」中选择朗读所用的引擎：

- **Edge TTS（推荐）**：由微软提供的在线语音，音色自然、无需任何配置和密钥，但需要联网。全新安装且尚未保存过语音设置时默认使用晓晓（`zh-CN-XiaoxiaoNeural`）。
- **系统语音**：使用本机语音库，完全离线。
- **自定义模型**：接入兼容 OpenAI `/v1/audio/speech` 的服务（自建 Kokoro、LocalAI 或云端 API）。

选择 Edge TTS 后，可在「音色」中挑选声音——默认只列出中文音色，打开「显示全部语言」可看到微软提供的全部语言；「语速」可选 0.8×、1×、1.2× 或 1.5×。点击「试听」确认网络、音色和扬声器正常，再按需打开「自动朗读 Agent 回复」。

Edge TTS 临时不可用时（断网、微软侧限制），自动朗读、聊天里手动点朗读和语音聊天都会自动改用系统语音，不会变成没有声音；只有「试听」会直接提示失败，方便你确认问题。已经保存过语音设置的用户不会被自动改成 Edge TTS，可随时在设置中自行切换。

## 语音聊天

语音聊天会打开一个独立小浮层：说完一段话后，Cortex 先转写，再把文字发送给当前聊天 Agent；回复完成后可按你的 TTS 设置朗读。它不是实时双向通话。

在「语音聊天」卡片中可以：

- 配置自动朗读与朗读引擎（见上一节）；
- 设置语音聊天快捷键；未设置表示关闭该快捷键；
- 打开「附带当前屏幕上下文」。打开后，语音聊天会尝试附上前台应用截图，便于 Agent 理解你正在看的内容。

屏幕上下文只在 macOS 可用，并可能要求系统授予「屏幕录制」权限。

## 系统级听写

系统级听写会把识别出的文字输入到你当前光标所在的位置，例如备忘录、浏览器输入框或聊天软件。

在「听写」卡片中可设置两种方式：

- 按住听写：按住快捷键说话，松开后识别并输入。需要 macOS「辅助功能」权限。
- 切换听写：按一次开始录音，再按一次停止、识别并输入。适合不方便持续按住按键的场景。

任一快捷键留空均表示关闭。三个语音快捷键不能与彼此或已经使用的系统快捷键冲突；若设置后出现失败提示，Cortex 会自动恢复之前有效的快捷键。

「始终显示听写栏」会在未录音时也显示屏幕底部提示。若识别期间你切换到另一个应用，Cortex 会放弃这次自动输入，避免把文字写到错误的窗口。

## 听写词典

将人名、产品名、缩写或项目术语加入「听写词典」。例如可以添加 `Cortex Desktop`、团队名称或内部产品代号。

词典用于让 Whisper 更倾向识别这些词。它是识别偏置，不是强制替换：模型仍可能识别错误，也不会把你没有说出的词自动插入文本。

## 语音识别模型

「模型管理」沿用原有的语音转文字设置：可选择本地 Whisper、已配置的服务商或自定义云端 API，并设置识别语言。

本地 Whisper 可离线工作，但首次使用需要下载模型。较大的模型通常识别更稳，但占用更多内存、首次转写也更慢。中文和多语言场景建议使用 multilingual Whisper 模型；识别语言保持「自动检测」适合混合语言。

## 权限与排查

| 现象 | 处理方法 |
|---|---|
| 看不到听写或屏幕上下文设置 | 这些系统级功能仅在 macOS 桌面端显示。 |
| 麦克风没有声音或没有设备名称 | 到 macOS「系统设置 → 隐私与安全性 → 麦克风」允许 Cortex，然后重新打开设置。 |
| 按住听写不生效 | 在「辅助功能」中允许 Cortex；切换听写可作为不依赖按键抬起事件的替代方式。 |
| 快捷键设置失败 | 换一个未被其他应用占用的组合；Cortex 会保留此前可用的组合。 |
| 没有把识别文字输入目标应用 | 确认已允许辅助功能权限，并在转写完成前不要切换前台应用。 |
| 词典没有完全纠正术语 | 词典只提供偏置。可以改用更大的本地模型、指定识别语言，或检查录音质量。 |
| 语音聊天无法附带截图 | 检查 macOS 屏幕录制权限；关闭屏幕上下文后仍可正常进行纯语音聊天。 |
| Edge TTS 试听失败 | 先确认能正常联网；若网络正常仍失败，多为微软侧临时不可用，可改用系统语音，稍后再切回。 |
| 朗读声音突然变成机器音 | Edge TTS 不可用时会自动回落系统语音。恢复联网后新的朗读会自动切回 Edge TTS。 |
