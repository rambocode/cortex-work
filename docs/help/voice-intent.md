# 使用语音助手意图理解

语音助手可以区分普通聊天和本地控制命令。你可以直接说：

- “退下”“退下吧”“退出语音助手”或“再见”：语音助手先简短确认，朗读结束后关闭语音球并恢复宠物窗口。
- “新建对话”：创建一段没有历史上下文的新会话。
- “开启屏幕上下文”：后续语音消息附带当前屏幕截图。
- “关闭屏幕上下文”：停止附带截图。

这些明确短句会在本机直接处理。例如“怎么退出语音助手？”是一个问题，会继续发给 Agent，不会误关闭。

退出确认播放期间可以直接说“等等”“停一下”或继续提出问题，也可以点击语音球、麦克风按钮或使用语音聊天快捷键打断；打断后会取消本次退出并重新聆听。为了避免语音助手听到自己的扬声器，播放期间会使用系统回声消除和更严格的人声确认，因此清晰、持续约 240ms 的近距离发声最容易触发；很短的爆音、风扇声和残余回声不会立即打断。

## 选择意图模式

进入「设置 → 语音 → 语音助手 → 意图理解」：

- **函数调用（推荐）**：没有额外分类等待。明确的本地控制句由 Cortex 处理，其余内容直接交给当前 Agent；Agent 继续使用现有 tools、MCP 和 skills 完成任务。
- **独立模型分类**：先用一个小模型理解自然表达的退出、新建对话和屏幕上下文命令。可以指定专用模型；留空则跟随全局默认模型。
- **关闭模型分类**：不调用独立分类模型，但明确的本地控制短句仍然有效。

独立模型分类最多等待 5 秒。模型不可用、网络失败或返回内容无法识别时，Cortex 会把原话当作普通聊天继续发送，不会丢失本次语音。

## 隐私提示

“函数调用”和“关闭模型分类”不会为了本地意图额外发送一次模型请求。“独立模型分类”会把本次转写文本发送给你选择的模型供应商，然后普通任务仍可能进入当前 Agent。需要完全避免额外分类请求时，请使用推荐的“函数调用”模式。
