# 使用 SenseVoiceSmall 本地语音识别

SenseVoiceSmall 可在本机完成中文、英文、粤语、日语和韩语语音识别。录音数据不会因本地识别
上传到云端；录音时应用会持续把声音交给本地服务，停顿结束后一次性显示整句文字。

## 开始使用

1. 打开“设置 → 语音 → 语音转文字”，开启语音识别。
2. 选择“本地 SenseVoiceSmall（离线）”。
3. 选择 Hugging Face 或 HF-Mirror，点击下载并等待状态变为“可用”。
4. 选择识别语言；混合语言可使用“自动检测”。
5. 回到对话，打开语音或听写并开始说话。首次启动会加载模型，后续句子会复用本地服务。

## 使用说明

- 每句话最长 30 秒，到时会自动提交。
- 当前版本不逐字显示临时结果；检测到停顿后显示一次最终结果，以避免文本反复跳动。
- 语音词典仍会用于支持 prompt 的在线识别；SenseVoiceSmall 本地 GGUF 不支持提示词偏置。
- 本地模型约 242 MiB，运行时通常占用约 500–900 MB 内存。
- 删除模型不会删除聊天内容；再次使用本地识别前需要重新下载。

## 常见问题

**首次使用为什么较慢？** 需要先下载并校验模型，第一次打开语音还要把模型载入内存。

**为什么说话时没有逐字文字？** 音频传输是实时的，但 SenseVoiceSmall 在句末执行整句识别；
这是当前设计，不是连接故障。

**识别失败会自动上传云端吗？** 不会。本地模式失败时会直接提示错误，只有主动选择云端服务时
才会调用在线 ASR。

**模型一直无法下载？** 切换另一个下载源并重试，确认网络允许访问 Hugging Face 或
HF-Mirror。中断下载不会留下可被加载的不完整模型。

**没有声音或立即停止？** 在系统隐私设置中允许 Cortex 使用麦克风，并检查输入设备是否被
其他应用独占。重新打开语音会重新初始化采集与 VAD。

平台支持：macOS Apple Silicon、macOS Intel、Windows x64；Linux 暂不支持本地模式。
