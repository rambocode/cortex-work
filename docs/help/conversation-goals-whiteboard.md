# 使用目标模式与白板

## 目标模式

在会话输入框左下角点 `+`，选择“追求目标”，输入希望 Agent 持续完成的目标并发送。也可以使用：

- `/goal`：进入目标输入模式
- `/goal <目标>`：创建或替换目标
- `/goal pause`：暂停
- `/goal resume`：恢复并继续
- `/goal clear`：清除

输入框上方会显示当前目标、累计耗时和编辑、暂停/恢复、清除按钮。目标完成、遇到持续阻塞、达到预算或触发续跑安全上限后会停止自动执行。

## 白板

点会话最右侧工具栏的“白板”打开画布。可以手动创建矩形、椭圆、文字、箭头、直线和自由绘制，也可以调整属性、缩放和平移。

直接在会话里说“画一个登录流程图”“把选中的节点改成蓝色”等，Agent 会读取当前白板状态并更新画布。绘图指令会直接呈现在右侧白板中，会话里不会显示内部的画布代码。白板按会话独立保存，切换回来会恢复内容。
