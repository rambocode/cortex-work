# 查看 Agent 的思考与工具调用

Agent 开始思考或使用工具后，会在你的问题下方显示“工作过程”。运行结束后，它会自动收起并显示总步数及分类统计，例如“工作过程（19 步）· 读取了 4 个文件 · 调用了 4 个工具”。

- Agent 运行期间，工作过程会自动展开，方便观察当前步骤；运行结束后自动收起。
- 点击工作过程摘要，可展开思考、读取文件和工具调用列表。
- 点击列表中的单个项目，才会继续展开该项的思考内容或工具输入、输出。
- 点击“查看完整过程”，可进入包含耗时、筛选和跨轮事件的完整视图。

过程内容只用于当前运行期间的回顾，不会写入持久聊天历史。应用重启或开始下一轮后，旧过程可能不再保留；最终回答和业务卡片不受影响。
