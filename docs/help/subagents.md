# 使用子代理

个人工作区最右侧现在有一条常驻工具栏。点击机器人图标即可打开“子代理”面板；再次点击同一图标会收起面板。

## 开始使用

无需打开功能开关。主 Agent 默认可以使用子代理，并会根据当前任务自行判断不调用、调用一个或调用多个。

1. 保持“使用现有代理”开启，让主 Agent 从已配置角色中选择；关闭后会改用一次性匿名角色。
2. 按机器资源设置“最大并行子代理数”；达到上限的新任务会等待空闲槽位。
3. 用“单个会话的子任务上限”限制一轮对话最多创建多少个子任务。
4. 需要更多专项角色时，打开“扩展代理”，再启用需要的角色。
5. 展开任意角色，可覆盖运行 Agent、模型、推理强度或追加提示词。留空表示跟随默认配置。

这些配置既可以从最右侧“子代理”面板修改，也可以在“设置 → 子代理”中集中管理；两处实时同步。

基础代理共 8 个，始终可用；扩展代理默认关闭，避免一次暴露过多不需要的委派入口。
标记为“只读”的审查与研究角色不会修改工作区，即使主会话当前允许编辑。

## 会话中的子代理卡

子代理开始执行后，会话中会出现一张任务卡，显示角色、状态、耗时、步骤数和最新活动：

- 点击卡片主体可展开或收起结论。
- 点击“预览”可在卡片旁查看实时活动、最近步骤和当前结论；再次点击、按 `Esc` 或点击浮层外区域即可关闭。
- 点击“查看过程”可打开这一次子代理调用的完整运行详情，包括思考、工具输入输出、耗时和 token 统计。即使同一角色被调用多次，各次过程也不会混在一起。

预览与结论不会同时展开；从预览进入完整过程时，预览会自动关闭。原始过程只在当前应用运行期间保留，重启后仍可回看卡片状态和结论，但不恢复完整工具日志。

最终回答仍由主 Agent 根据当前会话上下文和子代理返回结果统一整理。子代理原始输出不会直接冒充最终回答。
