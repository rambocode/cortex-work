# 语音朗读帮助

## 使用 Edge TTS

在「设置 → 语音 → 语音引擎」选择 **Edge TTS（推荐）**。新安装且尚未保存过语音设置时，会默认选择晓晓（`zh-CN-XiaoxiaoNeural`）。

1. 在「音色」中选择喜欢的声音。
2. 在「语速」中选择 0.8×、1×、1.2× 或 1.5×。
3. 点击「试听」确认网络、音色和扬声器均正常。
4. 如需每轮回复自动朗读，打开「自动朗读 Agent 回复」。

## 注意事项

- Edge TTS 由微软提供，需要联网；「试听」失败会显示原因，请检查网络后重试。
- 自动朗读、聊天朗读和语音聊天在 Edge TTS 临时不可用时会自动改用系统语音，避免没有声音。
- 系统语音保留为离线选项；也可选择「自定义模型」接入兼容 OpenAI 的 TTS 服务。
- 已保存过语音设置的用户不会被自动改成 Edge TTS，可随时在设置中自行切换。
