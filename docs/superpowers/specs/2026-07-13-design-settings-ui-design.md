# 设计设置页紧凑化 UI 设计

## 背景

当前“设置 → 设计”分区将五组配置按单列卡片纵向排列。字段本身已经完整，但页面存在三个可用性问题：卡片纵向过长、同类选择项各占一整行、基础设置与高级设置缺少清晰层级。用户需要在不改变配置语义和持久化行为的前提下，提高信息密度和扫读效率。

## 目标

- 在桌面宽度下显著减少纵向滚动。
- 让用户快速识别“代码、画布、工作目录、设计系统、Agent”五个配置域。
- 保留现有字段、文案、数据类型、更新方式和持久化链路。
- 保持与设置页现有视觉语言一致，同时让设计分区具有更清晰的专业工具感。
- 在窄窗口下自然回落为单列，不出现控件挤压、文本裁切或横向滚动。

## 非目标

- 不修改 `designSettings` 数据模型、默认值或归一化逻辑。
- 不新增、删除或重命名设置项。
- 不改变其他设置分区的共享控件样式。
- 不引入新的组件库、图标库或持久化机制。
- 不重构整个设置页导航。

## 页面结构

`DesignSettingsSection` 增加一个作用域根容器，内部由页头、状态摘要和自适应卡片网格组成。

### 页头与状态摘要

页头沿用现有标题和描述。其下增加一条紧凑摘要栏，展示三个当前值：

- 目标视口：桌面、平板或手机。
- 默认视图：预览或代码。
- 设计系统：当前预设名称。

摘要只读，不提供第二套编辑入口；点击和键盘焦点仍集中在正式表单控件上，避免状态来源重复。

### 自适应卡片网格

桌面宽度采用两列网格：

1. “设计 → 代码”位于左列。
2. “画布默认值”位于右列。
3. “设计工作目录”横跨两列。
4. “设计系统”位于左列。
5. “设计 Agent”位于右列。

当可用内容宽度不足约 760px 时，网格切换为单列，所有卡片按上述顺序排列。

### 卡片层级

每张卡片包含：

- 一个来自现有 `Icon` 集合的语义图标。
- 卡片标题。
- 卡片主体设置项。

字段继续使用现有翻译说明，不新增卡片级文案。卡片保持现有边框和背景体系，减少过大的上下留白。图标只用于导航和识别，不使用装饰渐变或大面积强调色。

## 控件布局

### 设计 → 代码

- 技术栈提示保持单行输入框并占满卡片内容宽度。
- 两个布尔设置使用紧凑设置行：标签与说明在左，开关固定在右。

### 画布默认值

- 目标视口、默认视图、画布底色组成紧凑字段网格。
- 双列页面下，目标视口与默认视图并排，画布底色横跨字段网格整行；卡片自身宽度不足时自动变为单列。
- 实时刷新、设备外框继续使用紧凑设置行。

### 设计工作目录

- 输入框占据主要空间。
- “选择目录”为主要操作，“恢复默认”为次要操作。
- 窄宽度下按钮允许换行到输入框下方，保持完整点击区域。
- bridge 不可用时沿用当前禁用行为。

### 设计系统与 Agent

- 设计系统保留品牌色、语气、预设和指南字段。
- Agent 保留模型与生成提示词字段。
- 多行文本区允许纵向调整，提供足够的最小高度。
- 输入框、选择器和文本区统一使用现有设置页控件视觉，不创建重复表单体系。

## 样式边界

- 新样式全部限定在设计分区根类下，例如 `.pw-design-settings`。
- 不修改 `.pw-scard`、`.pw-input`、`.pw-btn` 等共享类的全局表现。
- 复用现有颜色 token、边框 token、字号和圆角，不写死亮色主题专用颜色。
- 深色主题依靠 token 自动适配；若摘要栏或图标底色需要补充，只在设计分区作用域下添加深色规则。
- 尊重设置页现有滚动容器，不新增嵌套滚动区域。

## 数据流与错误处理

所有可编辑控件继续直接调用 `setDesignSettings`，持久化仍由 personal store 负责。目录选择继续通过 `DesktopBridge`：

1. 点击“选择目录”调用 `pickDirectory()`。
2. 返回非空目录时写入 `defaultWorkspaceRoot`。
3. 用户取消时保持原值。
4. 点击“恢复默认”调用 `designWorkspaceRoot()` 并写回结果。
5. bridge 或对应方法不可用时按钮保持禁用。

本次不新增异步状态或错误提示机制，避免改变现有交互合同。

## 可访问性与交互状态

- 保留所有原生表单控件的键盘操作和标签关系。
- 摘要信息使用普通文本，不进入多余的 Tab 顺序。
- 按钮、输入框、选择器和开关保留现有 hover、focus、disabled 状态。
- 图标标记为装饰内容，不重复朗读卡片标题。
- 控件点击区域不小于当前共享控件尺寸。

## 测试与验收

### 自动化测试

- 渲染设计分区时存在作用域根容器、摘要栏和五个语义卡片。
- 摘要栏反映 `defaultViewport`、`defaultCanvasView` 和 `designSystemPreset` 当前值。
- 输入、选择、开关仍调用现有 store 更新链路。
- 目录选择、取消、恢复默认和 bridge 缺失行为保持不变。
- 静态样式测试确认桌面双列、工作目录跨列和窄窗口单列规则存在。

### 视觉验收

- 在当前截图对应宽度下，代码与画布卡片并排，工作目录横跨整行，设计系统与 Agent 并排。
- 页面首屏可看到更多完整配置域，纵向滚动距离明显缩短。
- 760px 以下内容单列，无横向滚动、控件裁切或按钮重叠。
- 亮色与深色主题下文字、边框、摘要和交互状态均清晰。
- 其他设置分区视觉不发生变化。
