# 更新日志

## [0.1.39] - 2026-07-13

- **设计设置焕新**：设计设置页改为紧凑响应式卡片布局，新增关键配置摘要；宽屏双列展示，窄屏自动回落，原有设计配置与工作目录操作保持不变。
- **会话重命名**：会话列表支持原地重命名；手动名称会持久保留，不再被首条消息的自动标题覆盖，且重命名不会改变会话最近活动排序。
- **修复桌面宠物设置同步**：独立宠物窗口现在以主窗口保存的造型、尺寸、显隐和行为设置为准，避免启动后显示旧造型或默认配置。
- **修复 Pi 首轮无回复**：推理模型只生成思考而没有最终答复时给出明确重试提示；同时减少 Pi 冷启动期间误导性的超时告警。

## [0.1.38] - 2026-07-10

- **新功能·用户记忆**：会话、写作、设计从此共享一份持久的用户记忆。应用会像人做梦一样，在会话空闲和每日凌晨自动回放近期对话，提炼你的画像、偏好与项目背景并遗忘过时内容；整理结果自动注入之后的每次 AI 对话，越用越懂你。
- 设置新增「记忆」页：可查看和编辑三个记忆分区（手写内容优先级最高）、一键「立即整理」、查看整理历史、清除记忆，或直接打开本机记忆文件（markdown，可自行编辑备份）。
- 记忆默认开启，可在设置中一键关闭；关闭后不再注入对话，后台整理同步停止。

## [0.1.37] - 2026-07-10

- **修复**：写作工作台在应用窗口较窄时，右侧写作助手栏会被挤出可视区域、内容被裁剪；现窄窗口下自动收起助手栏，拖宽窗口后自动恢复。
- **Codex 模型**：新增 GPT-5.6 三档模型可选（Sol / Terra / Luna）。

## [0.1.36] - 2026-07-10

- **个人工作区项目上下文侧栏重构**：侧边栏项目上下文区域重新设计，交互与展示更清晰。
- **修复**：侧边栏归档会话入口在重构后被遗漏，现已恢复。

## [0.1.35] - 2026-07-09

- **对话分支回复**:刷新按钮支持分支式重新生成回复,不覆盖原回复;多个回复分支可通过分页器来回切换查看。
- **修复**:编辑或重新发送问题时,不再丢失原消息已引用的文件;写作空间新建文件夹的输入框改为就地显示在所选目录下方,且新建的空文件夹不再消失不见。

## [0.1.34] - 2026-07-07

- **全新「写作工作台」**:侧边栏新增写作入口,整窗三栏布局——左侧写作空间与文档树、中间 Markdown 编辑器、右侧写作助手。可把任意本地目录添加为写作空间,文档树只显示 Markdown 与 PDF,添加空间后自动打开目录里的第一篇文档。
- **四档编辑视图**:富文本(所见即所得)/实时预览/仅预览/源码自由切换,各视图阅读版心对齐;支持字号步进、排版字体与行距设置、粘贴图片自动落盘、字数统计,以及打字续写(灰字补全)与 ⌘K 就地改写。
- **写作助手改稿闭环**:选中文本一键引用,发送后 AI 直接改稿,改动以行级红绿 diff 逐块审阅(接受/拒绝),未变更区域自动折叠;支持多会话、快捷指令(内置 + 自定义)、模型与思考强度选择、输入 / 呼出技能、推理过程与流式回复展示,可参考空间内其它文档自动注入检索上下文。
- **导出与生成**:一键导出 DOCX/PDF/HTML/PNG 或复制富文本;选中文本可生成信息图;支持 PDF 阅读与选中文字带页码引用。
- **修复**:添加写作空间后立即加载报「路径不在允许范围内」;改稿 diff 审阅看不出变更位置;窗口过窄时中栏被左右栏挤压等问题。

## [0.1.33] - 2026-07-05

- 新增「AI 设计工作台」：个人工作区新增整窗三栏式设计画布(设计稿树/画布/设计对话)，可用自然语言让 AI 生成、编辑网页/组件设计稿，支持多页面并行生成、实时预览与一键从设计稿生成代码。
- 设计对话支持工具调用聚合展示、markdown 富文本渲染，并修复了多个页面切换/删除时的状态残留与显示异常问题。

## [0.1.32] - 2026-07-04

- **桌面宠物脱离主窗体**：宠物现在是一扇独立的小窗口，可以直接拖出聊天窗口、放到桌面任意位置或叠在其它应用上方，不再局限于窗口内部。
- **新增宠物造型「薄荷」**：多一个圆润薄荷绿的可选造型。
- **运行过程详情弹层**：点击运行状态图标可查看本轮完整工具调用链——耗时、事件数、工具调用次数、Token 消耗（含缓存占比）与费用统计，支持按工具/事件类型筛选，输入输出可展开查看；修复 Codex 多轮网页搜索在界面上显示成"空调用无结果"的问题。
- **修复**：Intel Mac（x64）版本可能出现的权限相关原生模块崩溃问题；补全快捷回复助手所需的麦克风/日历等系统权限声明。

## [0.1.31] - 2026-07-04

- **全新「快捷回复助手」**：在任意第三方 app（IM、邮件等）双击 ⌘ 或按住 Fn 说话，即可唤起不抢焦点的浮动候选气泡，基于当前对话自动生成多条回复草稿；左右切换候选、回车直接写回目标输入框，「翻牌」可再要一条不重复的新草稿。
- **语气记忆与学习**：按档案/通用/IM/邮件/公开分区记忆你的表达习惯，支持手写补充笔记；「从我发出的消息学习语气」一键蒸馏出风格要点，自动注入后续生成。
- **生成模型自选**：可在设置中为快捷回复单独指定模型供应商与模型，不与主对话共用同一路配置。
- **日历感知**：自动读取未来几天的空闲时间段，回复涉及约时间时能给出可用时间建议。
- **渠道连接与权限中心**：支持 Slack / Gmail / Lark 凭据校验与连接状态管理；新增辅助功能、屏幕录制、麦克风、语音识别、日历五项权限的统一状态展示与授权引导。
- **微信等应用定位修复**：修复部分应用（如微信）因系统辅助功能信息缺失导致回复气泡定位偏移、对话内容误识别的问题。

## [0.1.30] - 2026-07-02

- **会话实时活动行**：AI 回复过程中在聊天流内实时显示思考与工具执行进度，慢工具附带心跳提示不再「假死」；会话预热让首次响应更快。
- **Pi 思考过程透出**：推理模型（如 DeepSeek）的思考内容现以增量实时渲染，与 Claude 表现一致；同时修复此类模型输出导致的日志刷屏。
- **Windows 发布包精简**：不再提供 zip 压缩包，请使用安装程序（.exe）；macOS 与 Windows 的自动更新均不受影响。

## [0.1.29] - 2026-07-02

- **全新个人任务系统**：任务支持无限层级子任务、推迟/截止日期、标签、旗标、预计时长、定时提醒（原生通知）、重复任务（支持分钟/小时与按周/按月自定义规则）、文档附件与归档；任务可一键委派给 agent 执行并自动回写进度状态。
- **项目管理独立窗口**：OmniFocus 式三栏工作台——左侧多层项目树（文件夹/项目嵌套、并行/顺序两种执行模式）、中栏大纲式任务清单（四档过滤、分组折叠、行内编辑与快速新增）、右栏任务详情；工具栏提供后退/前进、显示过滤、聚焦、快速入口（⌘O 命令面板）与显示/编辑字段自定义。
- **项目阶段管理**：内置软件项目、营销活动、产品设计、内容创作等阶段模板，支持自定义模板；新建项目选择模板即自动生成阶段，项目设置中可随时应用/更换模板；阶段标签可按状态过滤任务。
- **阶段 Timeline 视图**：日/周/月三档粒度的甘特时间线，阶段条按起止日期呈现，今日红线标记，「今天」按钮一键定位。
- **团队资源管理**：全局成员库与常用岗位标签管理；任务可分配多名成员并按小时设置预估工时。
- **项目设置**：项目描述与状态（进行中/暂停/已完成/已丢弃）管理，头部实时进度条（按任务完成比计算），删除项目需输入项目名确认防误删。

## [0.1.28] - 2026-07-01

- **修复自动更新误装 Intel 版本**：此前部分 Apple Silicon(M 芯片)用户升级后应用变成 Intel(需 Rosetta 转译)版本运行；现已修复，Apple Silicon 用户将正确保持原生 arm64 版本。
- **正式支持 macOS Intel 与 Windows 版本**：现在同时提供 macOS Apple Silicon、macOS Intel、Windows 三个平台/架构的正式安装包与自动更新。
- **Skills 面板重构**：Claude / Codex / Pi 三个 agent 的已装 skill 与插件改为分别管理，跨设备（`~/.agents/skills`）共享；面板可查看 Claude / Codex 自带的内置插件与 skill；Claude / Codex 现在也支持通过输入框 `/` 指令直接调用 skill。
- **输入框体验优化**：`/` 指令菜单支持模糊搜索、展示图标与来源标签；选中的 skill 以蓝色标签展示，可直接退格删除；新会话页接入 `/` 指令并默认展开 Skills 面板；发送消息后输入框立即清空，无需等待本轮回复结束；修复 Codex 内联图片流式渲染时的闪烁与布局抖动。
- **稳定性修复**：放宽长任务看门狗阈值，避免 Pi 子 agent 编排任务被误判超时终止；修复 Pi 未知消息帧类型导致的日志刷屏；侧边栏项目会话列表默认只显示 5 条、可展开折叠。
