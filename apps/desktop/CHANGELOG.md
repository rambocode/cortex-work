# 更新日志

## [0.1.26] - 2026-06-27

- **修复宠物显示旧造型**：此前选过「趴在输入框」行为的用户,升级后宠物仍显示旧版矢量造型。现宠物行为统一为「自由放置」并自动迁移历史设置,所有人都能看到新版 2D 序列帧宠物。

## [0.1.25] - 2026-06-27

- **桌面宠物 2D 游戏质感焕新**：宠物从矢量造型升级为真实手绘序列帧动画——「小柯」(猫)与「阿柴」(狗)两款宠物会自然呼吸眨眼、开心时原地蹦跳、久置打盹,并在你打字、Agent 思考 / 工作 / 回复时给出对应的状态反馈(铅笔、思考泡、齿轮、对话泡等)。
- **宠物设置精简**：默认「自由放置」——宠物停在你放的位置、可随手拖动;移除了对新宠物无效的颜色与行为设置;造型选择的预览改为展示真实宠物形象。

## [0.1.24] - 2026-06-27

- **子 Agent 编排可视化**：对话中新增「运行过程」面板，实时展示子 agent 三段编排（plan → execute → refine）进度；可通过 UI 开关控制面板显示，编排各段可透传推理强度设置。
- **响应式布局优化**：窗口设最小宽度，输入框宽度自适应，左侧栏在小窗口下自动收缩，解决内容溢出问题。
- **落地页激励文案轮换**：时段问候文案每 30 分钟自动轮换，并修复了缓存不更新的问题。
- 修复：Codex WS 重连复用连接时「startTurn 前须先 startThread」报错；编排 refine 段不再插入悬空段标题。

## [0.1.23] - 2026-06-27

- **Codex 执行过程可视化**:codex 会话现在在右侧「运行过程」面板按真实时序展示完整过程——思考与工具调用交错呈现(思考 → 工具 → 再思考 → 再工具),回复区只保留最终答案、不再混入过程叙述;面板随输出自动滚动到最新位置。
- **Codex 生成图片内联显示**:用 imagegen 生成的图片直接在对话中显示预览,不再只给文字。
- **Codex 多轮更快**:同一会话保持常驻连接,后续轮次不再重启进程、不再重新加载会话,响应更快。
- **新会话可选择 Agent**:新会话落地页与输入框支持直接选择 agent(Claude / Codex / Pi 等)。
- **输入框工具栏优化**:模型与推理强度合并为单个下拉、模型菜单只显示模型名并改为单面板下钻;新增「执行审批 × 访问范围」两个独立选项,可按需放开目录访问;图片与附件合并为单个上传按钮(点击弹菜单)。
- **统一思考强度选择**:各 agent 的思考 / 推理强度统一在一处选择。
- **新增 auto 执行档与目录授权**:权限模式新增 auto 档(按场景自动判定松紧),并可对会话授予额外目录的读 / 写访问。
- 修复:codex 续接会话报错、模型子菜单不可选 / 被裁剪、pi 新会话草稿 provider 回退等若干交互问题。

## [0.1.22] - 2026-06-26

- **Loop 工作流新增「便签」**(新功能):画布空白处右键即可添加彩色便签为流程做注释——支持拖动、缩放、双击编辑(Markdown 渲染:标题 / 加粗 / 链接 / 列表)、改色与删除。便签不参与连线与执行,纯作画布标注。
- **工作流节点体验优化**:
  - 单节点运行:选中节点点「运行」可单独执行该节点,节点状态圆点实时反映运行中 / 成功 / 失败。
  - 节点卡片改显属性摘要(如 HTTP 节点直接显示 GET),不再展示分类文字;工具栏图标与按钮交互优化(hover 高亮、删除按钮悬停变红)。
  - 修复节点配置面板:右侧面板加宽、长字段输入框不再溢出被裁,标签页与按钮样式更清晰。
- 修复 codex 续接会话因参数问题导致的报错。

## [0.1.21] - 2026-06-25

- **全新「Loop 工作流」**(新功能):可视化编排自动化流程——拖拽连线搭建节点图,内置 25 种节点(AI 智能体、生成图片、条件 / 分支 / 循环 / 合并等流程控制、数据处理、HTTP 请求、代码与自定义脚本、子工作流、人工审批等)。
  - 触发方式支持手动、定时(cron)与 Webhook;可「运行一次」端到端执行,实时查看每个节点的运行日志与历史记录。
  - 列表页全新设计:状态徽章、搜索与按状态筛选、最近运行结果一览;支持导入 / 导出工作流(JSON)、工作流级环境变量与自定义模块。
  - 可开放给 AI 调用:启用后 AI 助手能经 MCP 直接列出并运行你的工作流。
- **媒体生成**(新功能):新增「媒体生成」设置分区,支持图像等四种模态的生成配置(兼容 OpenAI Images / MiniMax 协议),并可作为工具注入对话由 AI 调用。
- **语音转文字**(新功能):新增「语音转文字」设置分区,支持本地 Whisper 模型的下载 / 校验 / 管理,在输入框直接将语音转成文字。

## [0.1.20] - 2026-06-24

- **设置页新增「已归档对话」**(新功能):集中查看已从侧边栏移除的对话——按所属文件夹分组、可搜索、并显示已归档数量。每条可一键「取消归档」恢复、点击标题直接打开会话,或永久删除。
- **闪记增强**:
  - 闪记可移动到不同项目(列表、写作面、详情三处入口,也可移回「无项目」)。
  - 写作面「源码 / 实时预览 / 仅预览」三档视图加宽,阅读与编辑更舒展。
  - 闪记面板按当前会话所在项目过滤,「未归类」统一改称「无项目」。
- 相对时间显示支持「周 / 月」粒度,较早的会话与笔记不再笼统显示「N 天」。

## [0.1.19] - 2026-06-24

- **聊天支持发送文档附件**(新功能):输入框可附带 PDF / Word(.docx) / Excel(.xlsx) / PPT(.pptx) / 文本(.csv/.txt/.md)文档——点附件按钮选文件、从系统或应用内文件树拖入、或直接粘贴。agent(claude / codex / pi)会按需读取文档内容,用于问答、总结、分析;文档以引用形式显示在消息气泡里,执行过程面板可看到 agent 调用「读取文档」的过程。
- **自动化详情页重做**:顶栏 / 运行历史 / 配置布局更清晰,提示词改由编辑弹窗与「更多」菜单访问,主区更聚焦。
- 设置页二级菜单缩进与 hover 视觉优化。

## [0.1.18] - 2026-06-23

- **全新「浏览器」设置页**(设置 → 应用 → 浏览器):
  - 一个总开关「允许 agent 控制内置浏览器」,清晰分区呈现。
  - **General**:可选本地 URL(localhost)默认在内置面板还是系统浏览器打开;一键清除所有浏览数据(带确认);批注截图模式(始终包含 / 询问 / 从不)——选「始终包含」时,把页面批注发送到对话会自动附带当前页截图。
  - **权限**:导航授权范围下拉——可选「仅外部网站需预授权」或「所有网站均需预授权(含 localhost)」。
  - **网站权限**:维护非本地导航的预授权 origin 白名单(添加 / 移除 / 重复校验)。
  - **开发者模式**:完整 CDP 访问开关(风险升高,启用前二次确认)。
- **设置菜单分组**:设置页左栏改为按「通用 / 模型与 Agent / 应用 / 个性化 / 自动化」分组,「浏览器」提升为独立分区,左栏加宽更易浏览。

## [0.1.17] - 2026-06-23

- 修复 pi 在**默认(只读)模式下用不了浏览器控制**的问题:新会话默认只读档会把浏览器工具挡掉,导致 agent 提示「没有 browser_navigate 工具」。现在内置浏览器控制工具在只读档下也可用(浏览器是沙箱环境,不会改动你的文件)。

## [0.1.16] - 2026-06-23

- 修复 0.1.15 安装后**启动即崩溃、无法打开**的问题(浏览器控制依赖的组件未被正确打包)。本版与 0.1.15 的新功能一致(让 agent 控制内置浏览器、pi 接入 MCP 等),请直接更新到本版。

## [0.1.15] - 2026-06-23

- **让 agent 控制内置浏览器**(新功能):开启后,agent(claude / codex / pi)可直接驱动内置浏览器——导航、点击、填表单、截图,以及读取页面文本和控制台报错,帮你走通流程或定位 bug;agent 发起导航时面板会自动打开,你可全程旁观、随时接管。在设置的「MCP」页开启;非本地站点支持预授权白名单,网络观测 / 无障碍树等高级能力作为按需开启的「完整 CDP」开关。
- **pi 接入 MCP**:pi 现在也能使用你配置的 MCP server(以及上面的浏览器控制),开箱即用,无需手动安装第三方扩展。
- **执行过程面板默认收起**,点击向下展开;运行中保留状态图标。
- 修复一次导航在聊天里出现**两张重复「网页预览」卡片**的问题。

## [0.1.14] - 2026-06-22

- **插件与扩展管理升级**:全新三层信息架构,统一管理插件 / MCP / 技能 / 市场;可浏览本机已装插件(与 codex 等共享标准目录互通)、一键启停并在下一轮对话中跨 agent 生效;插件详情页展示元数据、自带图标与捆绑技能,并支持「在对话中试用」。
- **MCP**:新增「连接自定义 MCP」表单(支持 cwd / 环境变量),新增 / 编辑改为独立页面。
- **自定义 agent**:支持通过配置文件(`~/.cortex-desktop/agents.local.json`)派生或覆盖 CLI agent——更换命令、追加参数、注入环境变量,无需改代码;并可在顶栏 agent 选择器里直接切换派生 agent。
- **聊天文件链接更好用**:可打开项目目录之外的生成文件(如 `outputs/` 里的产物),并按类型分发——文本用内置编辑器、其它(表格 / PDF / 图片等)用系统默认应用打开;修正会话里文件路径被误标灰色删除线。
- agent 的**思考过程与工具调用展示更完整**(thinking / 工具事件归一)。
- 修复 pi 扩展安装 / 列举偶发卡死的问题(子进程超时兜底)。

## [0.1.13] - 2026-06-21

- **稳定性**:修复某些情况下应用会无预警闪退的问题——后台扫描会话/文件目录遇到异常数据时,不再拖垮整个应用。
- 修复内置浏览器**网页预览卡片过宽**,以及链接「打开方式」菜单被遮挡的问题。

## [0.1.12] - 2026-06-21

- **内置浏览器**:agent 输出里的网址可点击直接在应用内打开,并在消息下方显示网页预览卡片;站点无法访问时显示优化的错误页(地址、原因、排查建议、一键重新加载)。
- 内置浏览器工具栏新增**截图**(复制到剪贴板)与**页面标注**(点选元素写评论、批量发送到 Chat 或终端),并支持**右键菜单**(返回 / 重新加载 / 检查)。
- **MCP 支持**:新增 MCP 服务设置入口与全局总开关,可注入到 agent。
- **会话续接增强**:支持续接历史会话、失败自动回退;长 prompt 不再受命令行长度限制;agent 运行更稳定(超时看门狗、取消更彻底)。
- **任务文档**:文档详情支持在线编辑,并可二次编辑后发送到聊天框 / 终端;tasks 视图全面支持多语言。
- 左侧菜单栏改为 macOS 原生磨砂半透明。
- 修复:选中 agent 执行详情文本后可正常复制(不再误折叠);修复任务文档 Markdown 预览列表标记丢失。

## [0.1.11] - 2026-06-21

- 自动化**完成后推送**:定时任务跑完可自动把结果推到已配置渠道,支持**飞书自定义机器人**(加签鉴权)与**应用内原生通知**,可在弹窗里按已配置渠道多选。
- 设置「通知」分区新增**飞书渠道配置**与**内部通知开关**,集中管理推送目标。
- 修复内置浏览器**拖拽起跳**问题。

## [0.1.10] - 2026-06-21

- 新增**内嵌浏览器面板**:右栏可直接浏览网页与本地 dev 预览(地址栏支持任意 https 站点),面板宽度可拖拽、默认向左展宽。
- **agent 产出的网页一键预览**:当 agent 起本地服务或生成本地 HTML 文件时,消息里会出现「预览网页」入口,点击即在内嵌浏览器打开(本地服务自动打开;本地文件经安全授权后预览),无需切到外部浏览器。
- 失焦时用**独立通知窗体**显示全局提醒,主窗在后台也能看到提示。
- Prompt 库(Skills)改进:新增「在访达中打开」按钮、目录内文件增删改后**自动刷新**(不再需要手动刷新或重开)、`SKILL.md` 用专属图标与高亮色更易识别。

## [0.1.9] - 2026-06-20

- 自动化新增「默认模板」：内置 11 个开箱即用模板（每日 AI 新闻、英语单词、睡前故事、工作周报、历史上的今天等），新手一键即可创建定时任务；模板画廊默认展示在自动化页顶部。
- 自动化定时新增「一次性」类型：可指定具体日期与时间只触发一次（如体检预约、会议前提醒），错过时机会在下次启动补跑一次。
- 自动化运行历史增强：支持运行详情页、历史分页、删除记录与一键复制输出。
- 新增 pi 扩展市场：在设置内浏览、安装、启用 / 禁用、卸载扩展（新增「扩展」标签页）。
- 新增独立的 Agent 跟踪窗口与 console 日志流，便于排查 Agent 执行过程。
- 个人工作区改进：支持手动压缩上下文（/compact）、slash 命令下拉支持 ↑/↓ 键盘选择、会话操作溢出菜单、follow-up 排队条数提示，并修复若干扩展命令的输出显示问题。

## [0.1.8]

- 更新流程改为用户主导：发现新版本时仅在标题栏提示，点击查看更新内容后再手动下载。
- 新增更新内容弹窗，展示版本号与本次更新说明。
