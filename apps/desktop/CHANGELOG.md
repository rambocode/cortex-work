# 更新日志

## [0.1.59] - 2026-08-11

- **会话过程全新呈现**：个人会话的消息流按新规格重做。AI 干活的过程以时间线展示，阶段随进度自动展开与收起，完成后一眼能看到这一轮花了多久、读了哪些文件、调用了哪些工具；工具执行细节收成单行，点开才展示完整命令与输出，出错的步骤保持展开并标红。任务清单也换成独立的进度卡片。
- **界面更清爽**：个人会话取消了消息头像与消息头，左右气泡本身已说明是谁在说话，版面更干净、可读内容更多。子代理的执行过程不再混进主会话流，它有自己的卡片和入口，主会话的耗时统计也不再把子代理干的活算进来。
- **审批更可靠**：Cortex 会话统一走同一套操作审批通道，AI 调用敏感能力（尤其是电脑操作类）时的授权确认更稳定一致，不会出现该弹窗却直接放行的情况。
- **移除项目时间线**：项目时间线功能已下线，相关入口与设置一并移除。日常记录与回顾请使用会话与首页。
- **快捷回复设置调整**：快捷回复的设置面板重新排版，触发键配置更清楚易改，改完即时生效。
- **文档解析与长消息修复**：修复了往会话里放入文档时解析失败的问题；过长的用户消息现在会自动折叠，可展开查看全文，不再把整个屏幕刷满。

## [0.1.58] - 2026-08-10

- **会话随意分屏**：聊天窗格现在支持拆分——把会话拖到当前窗格的上、下、左、右任意一侧即可分屏，横向并排的数量不限。多个会话同屏对照、各聊各的，查资料、比答案不用再来回切换。
- **目标白板**：新增会话目标白板，从右侧栏一键展开。AI 会把当前任务的目标与进展整理到白板上，边聊边更新，长任务做到哪一步一目了然，白板内容会随会话保存。
- **子代理更好用**：子代理管理全面升级——可以创建自定义子代理，起名、选头像、定职责都由你说了算；新增自动角色，AI 会按任务类型自动挑合适的角色去干活。委派出去的任务在会话里以卡片形式实时展示进展，点开就能查看完整执行记录。
- **会话过程时间线**：AI 处理你的请求时都做了什么——思考、调用工具、委派子代理——现在按时间线逐步展示，每一步进行到哪里都看得到，不再是一个只会转圈的黑盒。
- **记录保存更稳**：会话与子代理记录的本地保存机制加固，修复了多窗口或快速操作下记录可能被互相覆盖、意外丢失的问题。
- **白板绘图修复**：修复了会话中让 AI 往白板上绘图偶尔不上屏、图片素材加载失败的问题，白板内容的展示与保存整体更可靠。

## [0.1.57] - 2026-08-08

- **本地识别再进一步**：语音识别现在支持完全本地的流式识别引擎，边说边出字更跟手，音频不出本机。相关模型的下载与切换在 设置 › 语音 中完成，切换后立即生效。
- **喊一声就唤醒**：新增唤醒词功能，不用点按钮、也不用记快捷键，直接喊出唤醒词就能唤起语音助手。唤醒识别全程在本地完成，不会把日常环境音上传。
- **说退下就真的退下**：语音助手现在能听懂「你先下去吧」「我们重新聊」这类自然口语，并真的执行——关闭语音球、开一段新对话、打开或关掉屏幕画面的参考。以前它只会嘴上答应、语音球照常挂着。执行前会先把告别语说完再收起，你中途插话则取消。
- **回答边生成边念**：AI 的回复不再等整段生成完才开口，写出一句就念一句，等待时间明显缩短，长回答的体感差别最大。
- **口令认得更松**：像「停一下」「别念了」这类控制口令，即使发音不标准、识别有偏差，也能凭读音匹配上并零延迟生效，不必一字不差。
- **语音球更耐看**：语音球的画面渲染整体重做，动效更顺滑、状态变化更清楚，长时间开着也不占资源。
- **思考强度不再走样**：部分模型（如 DeepSeek 新版）只支持有限的思考档位，但界面照旧显示全部选项，出现「选了中等、实际按高强度发出」的偏差。现在下拉里只列出当前模型真正支持的档位，显示的就是实际生效的。
- **协作者遵守思考设置**：让 AI 派出子任务或做单次生成时，你设定的思考强度此前会丢失、一律按默认强度跑。现在会如实带上，复杂任务的思考深度符合预期。
- **打断朗读不再报错**：打断 AI 朗读时后台会记一条错误，虽不影响使用但会污染日志排查，现已按正常流程处理。

## [0.1.56] - 2026-08-08

- **本地识别换新引擎**：本地语音识别从 Whisper 换成 SenseVoiceSmall，模型体积更小、识别速度更快，且支持边说边出字，说话时就能看到文字实时上屏，不必等整句说完。中英日韩粤语通吃，中文短句准确度提升明显。原有的本地模型下载与管理入口保持不变，在 设置 › 语音 中即可切换。
- **听懂控制指令**：语音球现在能分辨「你在跟它说话」还是「在下达控制指令」——说「停一下」「别念了」会立刻停止朗读，说「退下」「你先下去吧」会直接关闭语音球，而不是把这些话当成问题发给 AI 去回答。关闭前会先把告别语念完再收起，不会说到一半被掐掉。该功能可在 设置 › 语音 中关闭。
- **朗读中可随时打断**：AI 念到一半时你直接开口说话，它会立刻停下并转去听你说，不用等它念完或手动点停止。打断后立即进入识别状态，接着说就行，对话节奏更接近真人交流。
- **不再被自己的声音打断**：外放播放时收到的回声、以及环境噪声不会再被误判成你在说话，朗读期间的插话门槛做了单独调校——真正开口才会触发打断，敲键盘、空调声或 AI 自己的声音都不会让它无故中断。

## [0.1.55] - 2026-08-06

- **语音助手上线**：语音聊天从独立小窗改成一颗悬浮语音球，走的是和打字输入完全相同的会话管线——你在语音里交代的事，AI 真能调用电脑操作、定时任务、日历、MCP 与技能去做，不再是只能闲聊。说完自动发送、回复播完自动重新开麦，可连续多轮。入口在宠物悬停时的麦克风按钮，也可继续用全局快捷键唤起（宠物关掉时同样能用）。
- **断句更准**：判断「你说完了没」改用神经网络语音检测，空调声、键盘声、街边噪声不会再被误当成说话而提前提交，说话中的自然停顿也不会被切断。模型加载失败时会自动退回原来的音量判断，不影响使用。
- **录音更干净**：语音输入开启了回声消除、噪声抑制与自动增益，外放播放时不易把自己的声音录进去，识别准确率更稳。
- **修复正式包崩溃**：0.1.54 正式安装包中 pi 的两条执行路径均会因缺少运行时依赖而报错，导致对话与单次生成任务无法启动，现已修复。

## [0.1.54]

- **会话管定时任务**：现在可以直接说「每天早上 9 点帮我总结一下 AI 新闻」来创建定时任务，也能查看状态与执行结果、修改时间、暂停、立即运行或删除。新建、修改、删除与立即运行都会先弹确认框，需要你点「允许」才生效；AI 代建的任务在列表中带「AI 创建」角标，任务用的 Agent、模型与工作目录跟随当前会话。仅在 Cortex 会话中可用，可在 管理 › MCP 中随时关闭。
- **会话查建日程**：接入 macOS 系统日历后，可以问「我下周三下午有空吗」「明天几点有会」，也可以说「帮我把周五下午 3 点的评审记到日历」——创建前会先向你确认。需要在 系统设置 › 隐私与安全性 › 日历 中授予「完全访问」；此前「仅添加」权限下点「去授权」毫无反应的问题也已修复，现在会直接打开对应的系统设置页面。
- **产物即时预览**：AI 生成的网页、图表、SVG 与文档不再只是一段代码——现在会在会话里直接渲染成卡片，后续修改原地更新并标注版本，右侧新增产物面板可放大查看，重启后仍可回看。所有内容都在隔离沙箱中运行，不会触碰你的本地数据；AI 还能在沙箱里运行 JavaScript 完成计算与数据处理。
- **语音全面升级**：新增语音聊天浮层——说完自动发送、回复播完自动重新开麦，可连续多轮对话且记住上下文；新增系统级听写，全局快捷键在任意应用中口述输入。朗读默认接入免配置的在线音色，起播明显更快，点停止立即生效；转写结果可经 AI 自动纠错同音字与专有名词。相关设置合并为统一的「语音」分区，语音聊天可单独指定模型与提示词。
- **宠物大更新**：设置里新增宠物图鉴，可从 4000 多只宠物中搜索、筛选、随机浏览并一键换装。宠物现在会实时反映会话状态——AI 思考、执行工具、等你审批、任务失败都有对应姿态，状态变化时冒出气泡提示；尺寸改为直接拖右下角手柄或滚轮缩放。同时修复了切换动作时宠物短暂消失、换显示器后跑出屏幕找不回的问题。
- **能读更多文档**：会话附件支持的文档格式从 7 种扩到 23 种，补上 .doc / .ppt 旧版 Office、RTF、EPUB、ODF 等常见格式；解析结果保留标题、表格与列表结构，AI 阅读表格类文档的准确度明显更好。
- **连接测试可视化**：供应商「测试」不再是一直转圈的黑盒，会逐步展示运行时加载、鉴权、请求、响应各环节，出问题时能看清卡在哪一步。同时修复「测试通过但聊天不通」的假象——此前测试会忽略你填写的自建网关地址；经网关调用推理模型被拒绝 temperature 参数时也会自动重试而非直接失败。
- **修复正式包报错**：0.1.52 / 0.1.53 正式安装包缺少模型运行时依赖，导致所有供应商的连接测试报「模型运行时不可用」，快捷回复、深度研究、每日汇总与写作在使用自定义供应商时也会失败，现已修复。
- **其它修复**：侧边栏头像菜单切换「显示宠物」后重启被回滚的问题已修复；语音设置中本地识别模型卡片文字挤成一行的排版错乱也已修复。

## [0.1.53] - 2026-08-04

- **自定义供应商可直接聊天**：设置里保存的自定义供应商终于能在会话中真正使用。此前保存成功、聊天却报「No API key found for azure-openai-responses」——应用悄悄换成了另一个供应商；现在解析不到供应商会当场明确报错并中止，绝不静默换模型。自动化、工作流等后台单发任务也补上了同样的守卫，不会在你不在场时跑成别的模型。
- **聚合网关一键接入**：新增网关接入向导，填好网关地址与密钥后自动拉取可用模型清单并生成供应商配置，不用再手写 JSON。
- **能力不用手填**：模型的图片输入、上下文长度等能力改为自动识别，不再需要逐项手填五组数字。内置目录没收录的模型也能直接启用（按保守默认，标注为「仅文本」），需要更准确的能力时再「参照」一个已知模型一次点选继承即可；能力来源会在模型列表中如实标注是来自目录、参照还是保守默认。
- **网关模型开箱可用**：接入地址少填或多填 `/v1` 都能自动兜住；经网关调用推理模型时不再出现「invalid value: developer」这类被上游拒绝的报错。
- **自定义供应商也能发图**：会话中的图片能力判定现在认识自定义供应商，只要模型支持图片输入就能正常发图，不会再被误判丢弃。
- **状态更清楚**：设置页的每条自定义供应商会显示「在聊天中可用」，一眼看出哪些配置真正生效。
- **密钥不落明文**：自定义供应商的密钥在配置文件中只保留引用，真值仅在会话进程启动时注入，不会明文写入磁盘。
- **聚合网关成为独立的接入类型**：new-api / one-api 这类网关不用再从「自定义供应商」里绕道进入，设置→模型服务多了一个与「订阅登录 / API Key / 云平台」并列的「聚合网关」分区，填地址与密钥即可接入；已接入的网关可以直接点「编辑」回到可视化向导重新挑选模型，不必再手改 JSON。
- **自定义供应商不再只能聊天用**：快捷回复草稿、深度研究、每日汇总、写作续写与 Cmd-K 现在都能用自定义供应商与网关模型；此前把默认模型设成这类模型时这些功能会直接失败。供应商的「测试」按钮也不再对它们报「模型不存在」。
- **修复网关配置存不进去**：配置里含 `maxTokensField` 这类协议开关时会被误判成「疑似明文密钥」而拒绝保存，且这个字段本就无法改写成密钥引用，等于完全卡死。
- **修复会话中切换供应商无效**：聊天进行中切到另一个供应商的模型会失败并悄悄回滚，现在会在下一次发送时自动重启会话并保留上下文。
- **API Key 供应商也能填自定义接口地址**：此前只有云平台那一类有这个入口，现在每个 API Key 供应商行都可以展开填写自建网关 / 代理地址。
- **修复模型列表浮层被裁切**：点击「N 模型」弹出的列表下半截会被裁掉，靠近页面底部时还会跑出窗口；模型 id 较长时也不再与能力标签挤成一团。

## [0.1.51] - 2026-08-02

- **媒体生成大升级**：图片、语音、音乐、视频四类生成全面扩充——新增 Grok、火山引擎（Seedream 图片 / Seedance 视频）、小米 MiMo 语音等供应商与模型，图片支持参考图改图与质量档位，视频支持首帧/末帧控制；设置中的媒体生成页改为四个标签分页，选择内置目录里的供应商即自动带出协议与模型，还能直接复用已在「模型」里配置的供应商密钥。
- **消息中心**：侧栏新增消息铃铛，自动化运行结果、Loop 播报、任务提醒和可用更新都会自动存档，保留 60 天——即使执行时没开着窗口，事后也能找到结果。侧栏底部同时改为头像菜单，闪记、自动化、Loop、设置等入口收拢其中，界面更清爽。
- **内置 Agent 更名 Cortex**：会话里的内置 agent「Pi」正式更名为「Cortex」，提及方式改为 @cortex；设置里原「Pi」分区更名为「模型」，更清楚地表明这是配置模型供应商的地方。
- **Cortex 能力补齐**：媒体生成与 Loop 工作流现在对内置 Cortex 同样可用（此前仅 Claude Code / Codex 生效）；同时修复子 Agent 委派、演示文稿生成等长耗时操作在 Cortex 下运行约 20 秒就被误判超时而中断的问题。
- **写作助手栏改版**：底部选择器与主会话统一，agent、模型、推理强度合并到同一个组合按钮，窄栏里不再挤到模型名显示不全；顶栏去掉重复的文件名、精简视图切换按钮，折叠按钮移到左栏更顺手。
- **密钥更安全**：媒体生成的 API Key 一律存入系统钥匙串加密保管，不再明文落盘；已有的明文密钥会在启动时自动迁移，无需手动操作。
- **菜单不再被裁**：根治模型、推理强度等弹出菜单在窗口边缘被裁掉一截或漂移错位的老问题——空间不足时自动翻转方向，仍不够就整体收回可视区域；另修正侧栏按钮与 macOS 窗口红绿灯差 1 像素的对齐瑕疵。

## [0.1.50] - 2026-08-01

- **模型能力修复（重要）**：修复选用 Pi 供应商时模型真实能力被覆盖的问题——此前发图片会被丢弃并提示「模型不支持图片」，思考强度、上下文长度也可能不准。现在模型能力一律以供应商官方目录为准，应用内只做只读展示。
- **Pi 供应商管理改版**：设置 → Pi 的供应商管理由弹窗改为平铺，按认证方式分为「订阅登录 / API Key / 云平台 / 自定义供应商」四区，粘贴即存、云平台可覆盖 Base URL、自定义供应商需显式声明模型能力；默认模型改为「供应商 → 模型」级联选择，只列已配置的供应商，连接测试前会先提示可能产生的费用。
